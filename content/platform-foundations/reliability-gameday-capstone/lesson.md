# Capstone — Reliability Game Day

Close the reliability loop: budget burn forces freeze, a controlled chaos inject tests abort, and a blameless postmortem leaves durable follow-ups.

## Release checklist

1. Record remaining budget and engage freeze
2. Plan single-pod chaos with abort + roles
3. Write postmortem + learning note
4. Commit the evidence pack clean

This capstone combines SLO burn, game-day facilitation, on-call handoff artifacts, and postmortem discipline.
