# Run a Budget-Aware Game Day

A game day is a facilitated rehearsal: roles, freeze gate, inject, abort, learn — under the same error-budget rules as production.

## Why it matters

Chaos without facilitation becomes vandalism. Budget-aware game days train the freeze ladder before a real burn forces it.

## Ticket focus

1. Agenda with roles, timeline, freeze gate
2. Success criteria + learning note with follow-ups

## Tip codes

- `GAME_ROLES` — facilitator / scribe / on-call
- `FREEZE_FIRST` — no inject when already over budget
- `LEARN_CLOSE` — follow-ups must change alerts, freezes, or runbooks
