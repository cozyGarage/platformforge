# Tag cloud resources for cost and ownership

> **Attribution:** Scenario adapted from [90DaysOfDevOps](https://github.com/MichaelCade/90DaysOfDevOps) cloud topics (Michael Cade, CC BY-NC-SA 4.0). Rewritten as an interactive PlatformForge exercise.

Untagged resources become mystery bills. 90Days cloud days emphasize ownership metadata — this lab enforces two required tags.

## Tasks

1. Update `/workspace/cloud/resource.json`:
   - `Environment`: `prod`
   - `Owner`: `platform-team`
2. Write `/workspace/cloud/POLICY.md` requiring Environment and Owner before deploy
